This repository includes small applications and exercises focused on logic building, DOM manipulation, user interaction, and basic backend integration.

- Arrays and objects
- DOM manipulation
- Functions and events
- Shopping cart logic
- Basic calculators
- Interactive web components
- JavaScript fundamentals
- HTML & CSS integration

##  Included Projects
